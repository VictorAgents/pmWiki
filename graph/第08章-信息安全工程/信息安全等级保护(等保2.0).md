# 国家信息安全等级保护 2.0 体系

## 1. 等保 2.0 五个保护等级划分
依据系统受到破坏后对**国家安全、社会秩序、公共利益以及公民/法人合法权益**的损害程度，划分为 5 个等级：

| 等级 | 级别名称 | 损害对象与严重程度 | 监管与实施要求 |
| :--- | :--- | :--- | :--- |
| **第一级** | **用户自主保护级** | 损害公民合法权益，不损害国家安全/社会利益 | 自主定级与防护 |
| **第二级** | **系统审计保护级** | 严重损害公民权益，或损害社会秩序/公共利益 | 公安机关指导，县级以上备案 |
| **第三级** | **安全标记保护级** | **严重损害社会秩序/公共利益，或损害国家安全** | **重点保护对象，地市级以上公安备案，每年开展一次等级测评** |
| **第四级** | **结构化保护级** | **特别严重损害社会秩序/公共利益，或严重损害国家安全** | 强制监督检查，每半年开展一次测评 |
| **第五级** | **访问验证保护级** | **特别严重损害国家安全** | 专门机构特别管控 |

## 2. 等保 2.0 安全要求架构
- **安全通用要求**：技术部分（物理环境、通信网络、区域边界、计算环境、管理中心）+ 管理部分（安全制度、管理机构、人员安全、建设管理、运维管理）。
- **安全扩展要求**：云计算安全、移动互联安全、物联网安全、工业控制系统安全、大数据安全。
