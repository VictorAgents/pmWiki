# 4.实施阶段

4. 实施阶段实施阶段的监理服务的基础活动主要是通过现场监督、核查、记录和协调,及时发现项目实施过程中的问题,并督促承建单位采取措施、纠正问题,促使项目质量、进度、投资等按要求实现。监理的主要活动包括:质量控制、进度控制、投资控制、合同管理、文档资料和协调等。
