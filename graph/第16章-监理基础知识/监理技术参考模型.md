# 监理技术参考模型

监理技术参考模型（Supervision Technical Reference Model）构成了信息系统工程监理的核心业务框架，通常被总结为“四控、三管、一协调”。

## 核心要素：四控三管一协调

### 1. 四控（四大控制）
* **质量控制**：确保工程满足质量标准和需求。
* **进度控制**：监督项目按计划时间表推进。
* **投资控制**（成本控制）：监督项目资金使用，防止超支。
* **变更控制**：对项目范围、进度、成本等变更进行严格审查和控制。

### 2. 三管（三大管理）
* **合同管理**：监督承建单位履行合同，处理索赔与违约。
* **信息管理**：收集、整理、存储和分发监理过程中的文档和数据。
* **安全管理**：监督系统安全设计与实施，以及施工现场的安全。

### 3. 一协调
* **沟通协调**：在建设单位（甲方）、承建单位（乙方）和监理单位（丙方）之间进行沟通、协调，解决争议和冲突。

## 考试要点（Exam Takeaways）
* **必考点**：熟记“四控、三管、一协调”的具体内容。
* **常见陷阱**：不要将监理的“变更控制”与承建方的“范围控制”混淆；监理的“投资控制”对应承建方的“成本控制”。
