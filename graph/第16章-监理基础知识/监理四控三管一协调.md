# 信息系统工程监理核心内容 (四控三管一协调)

信息系统工程监理单位受业主单位委托，依据国家法律法规、标准规范和监理合同，对工程实施“**四控、三管、一协调**”的全过程监督与管理：

## 1. 四控 (四大控制)
1. **质量控制 (Quality Control)**：审查承建单位技术方案、测试用例，监督开发过程与验收测试，确保工程质量符合标准。
2. **进度控制 (Schedule Control)**：审核进度计划与里程碑，监督实际进度，分析工期偏差并督促纠偏。
3. **投资控制 (Cost/Investment Control)**：审核工程预算、工程量和付款申请，控制工程款支付与签证。
4. **变更控制 (Change Control)**：严格控制工程范围、设计方案和合同条款的变更，遵循规范审批程序。

## 2. 三管 (三大管理)
1. **合同管理 (Contract Management)**：监督买卖双方履行合同约定的权利和义务，处理合同纠纷与索赔。
2. **信息与文档管理 (Information & Documentation Management)**：对工程全生命周期产生的监理文件、技术文档进行分类归档与跟踪。
3. **安全管理 (Security Management)**：监督物理安全、网络安全、数据保密和系统上线安全措施落实。

## 3. 一协调 (组织协调)
- **沟通协调 (Communication Coordination)**：协调业主单位、承建单位、第三方测试机构及设备供应商之间的工作关系与冲突。
