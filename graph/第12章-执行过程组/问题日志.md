# 问题日志 (Issue Log)

## 1. 概念定义
问题日志是用于记录和监督项目问题的项目文件。在项目执行过程中，不可避免地会遇到各种障碍、冲突和未解决的事项，问题日志有助于项目经理有效跟踪并确保这些问题得到解决。

## 2. 核心内容
- 问题描述及编号
- 提出者及提出日期
- 责任人（负责解决该问题的人）
- 目标解决日期
- 问题状态（如：未开启、处理中、已解决、延期）
- 最终解决方案

## 3. 生命周期流转 (ITTO)
- **产生过程**：首次作为 [[12.1 指导与管理项目工作]] 的输出被创建。
- **动态更新**：在整个执行和监控组中更新，特别是在 [[12.5 管理团队]]、[[12.4 管理干系人参与]]、[[13.2 控制资源]] 等过程中。
- **作为输入**：是解决冲突和指导后续工作的关键输入，输入到管理干系人参与等过程。

## 4. 考试要点 (Exam Takeaways)
- **风险与问题的区别**：风险是**未来**可能发生的不确定事件（记入[[风险登记册]]）；问题是**当前已经发生**、对项目造成负面影响且需要采取纠正措施的客观现实（记入问题日志）。
- **考试情境题**：“项目团队发现了干系人之间发生分歧...”，第一步往往是“更新问题日志”。
