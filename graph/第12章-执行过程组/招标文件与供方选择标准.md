# 招标文件与供方选择标准

## 1. 概念定义
- **招标文件 (Bid/Tender Documents)**：用于向潜在卖方征求建议书的正式采购文件。
- **供方选择标准 (Source Selection Criteria)**：买方在评估潜在卖方的建议书/投标文件时，用于客观评价和打分的基准体系。

## 2. 招标文件的常见类型
- **信息邀请书 (RFI, Request for Information)**：了解卖方的能力。
- **报价邀请书 (RFQ, Request for Quotation)**：价格是主要考量时使用（买标准品）。
- **建议邀请书 (RFP, Request for Proposal)**：技术复杂、需要卖方提供解决方案时使用。

## 3. 供方选择标准内容
通常包含多维度的权重打分卡：
- 技术能力和方法
- 价格和生命周期成本
- 过去类似项目的业绩和履约能力
- 资质和财务稳定性

## 4. 生命周期流转 (ITTO)
- **产生过程**：在规划阶段 [[11.23 规划采购管理]] 编制完成。
- **应用过程**：在执行阶段的 [[12.9 实施采购]] 中发送给卖方，并根据选择标准评估建议书，最终选定合格的卖方。

## 5. 考试要点 (Exam Takeaways)
- **价格不是唯一标准**：如果采购标的物高度复杂，建议书评估通常将技术方案的权重放得更高，而不是单纯采用最低价中标（最低价中标适用于标准化大宗商品采购，RFQ）。
