# 6. 面向 X 的设计

面向 X 的设计中的 X 既可以是卓越（excellence）的意思，也可以是产品的某种特性，如可靠性、可用性、安全性和经济性。前者追求整个产品在整个生命周期中的最优化，后者重点改进产品的某个特性。使用面向 X 的设计可以降低成本、改进质量、提高绩效和客户满意度。
