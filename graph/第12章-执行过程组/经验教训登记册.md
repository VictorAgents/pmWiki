# 经验教训登记册 (Lessons Learned Register)

## 1. 概念定义
经验教训登记册是记录在项目中获得的知识、面临的挑战、问题、实现的风险、机遇以及采取的有效（或无效）措施的项目文件。其目的是在当前项目和未来项目中改进绩效。

## 2. 核心内容
- **情况描述**：遇到的问题、挑战或成功的实践。
- **影响**：对项目（范围、进度、成本、质量等）产生的影响。
- **建议或行动**：为未来类似情况提供的建议、纠正措施或成功经验的复制指南。

## 3. 生命周期流转 (ITTO)
- **产生过程**：[[12.2 管理项目知识]] 的主要输出。
- **动态更新**：在项目的整个执行和监控过程中（如管理质量、控制采购等）持续更新。
- **收尾归档**：在 [[14.1 结束项目或阶段]] 时，经验教训登记册最终归档为**组织过程资产**（经验教训知识库）。

## 4. 考试要点 (Exam Takeaways)
- **尽早开始**：经验教训不是项目结束时才做的，而是从项目早期（甚至第一阶段结束）就开始记录。
- **隐性转显性**：管理项目知识的核心就是将专家的“隐性知识”转化为“显性知识”，经验教训登记册是这一转化的关键载体。
