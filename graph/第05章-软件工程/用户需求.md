# 2.用户需求

2. 用户需求用户需求描述的是用户的具体目标,或用户要求系统必须能完成的任务和想要达到的结果,这构成了用户原始需求文档的内容。也就是说,用户需求必须能够体现某种系统产品将给用户带来的业务价值,描述了用户能使用系统来做什么。通常采取用户访谈和问卷调查等方式,对用户使用的场景进行整理,从而建立用户需求。
