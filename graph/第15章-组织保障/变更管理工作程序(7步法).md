# 标准项目变更管理工作程序 (7 步法)

无论任何干系人提出变更，都必须严格遵循以下 7 步标准管理流程：

```
[1. 提出变更申请 (填写变更请求单)]
        │
        ▼
[2. 变更初审 (项目经理初审完整性与可行性)]
        │
        ▼
[3. 变更影响综合分析 (评估对进度/成本/范围/质量/风险的综合影响)]
        │
        ▼
[4. CCB 审查并做出审批决定 (批准 / 否决 / 推迟 / 修改后再议)]
        │
        ▼
[5. 发出变更通知并开始组织实施 (更新项目管理计划与基准)]
        │
        ▼
[6. 监控变更实施过程 (跟踪实际进度与质量，防范围蔓延)]
        │
        ▼
[7. 变更效果评估与收尾验证 (关闭变更单，记录至经验教训)]
```

## 案例题避坑要诀：
- 客户或领导口头提出变更时，**绝对不能立刻修改代码或计划**！必须先要求其**提交书面变更申请**，进行**综合影响分析**，并提交 **CCB 正式审批**。
