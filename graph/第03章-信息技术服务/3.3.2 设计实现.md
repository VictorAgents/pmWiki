# 3.3.2 设计实现

设计实现是在战略规划的基础上，采用过程方法来策划和实施服务设计，并基于健全的IT服务项目组织结构和规范化的项目管理，执行战略规划和服务设计所确定的方针、策略和方案，部署新的服务或变更的服务，包括落实新的组织结构、运行新的或变更后的管理体系、建设支撑服务运营的工具系统、提供有效的资源保障等。
