# 项目最终报告 (Final Project Report)

## 1. 概念定义
最终报告是项目收尾阶段生成的文件，用于总结项目（或阶段）的绩效。它标志着项目工作的正式结束，是对项目目标的完成情况的终极复盘。

## 2. 核心内容
- **项目层面绩效**：项目章程中概述的高层级目标的达成情况。
- **范围绩效**：对项目交付的范围与范围基准进行对比。
- **进度绩效**：将实际里程碑、完成日期与进度基准进行对比。
- **成本绩效**：实际发生成本与预算的对比。
- **质量绩效**：最终产品质量验证的结果。
- **最终业务价值**：项目如何满足了商业论证中的商业需求。
- **重大风险与问题**：在项目中发生过的重大问题及应对的有效性。

## 3. 生命周期流转 (ITTO)
- **产生过程**：[[14.1 结束项目或阶段]] 的核心输出。
- **结果**：产生后归档至组织过程资产（OPA），供未来的项目参考。

## 4. 考试要点 (Exam Takeaways)
- **收尾必做**：不论项目是成功完工、中途终止还是取消，都必须进行收尾，并编写最终报告说明项目当前的状态和提前终止的原因。
