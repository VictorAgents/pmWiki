# 4. 网络设备集成

网络设备集成工作通常基于软硬件集成项目中的网络规划与设计,进行设备上架和连接,并完成网络测试。网络规划与设计内容包括拓扑规划、设备安装部署设计、网络规划等。其中,网络规划通常又包括WAN规划、LAN规划、IP地址规划、路由规划、无线规划、网管规划、服务规划和安全规划等。网络设备通常包括核心交换机、汇聚交换机、接入交换机、路由器、中继器、集线器、网关、网桥等。
