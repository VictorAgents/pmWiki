# 传统质量管理七大工具 (旧 QC 7 大手法)

| 工具名称 | 核心图形特征 | 核心作用与使用场景 |
| :--- | :--- | :--- |
| **因果图 (鱼骨图 / 石川图)** | 鱼骨状树枝结构，根本原因分支展开 | **追溯根本原因 (Root Cause)**，发现问题背后的潜在缺陷源。 |
| **排列图 (帕累托图 / 80-20法则)** | 柱状图按频次从高到低排列，叠加累计百分比曲线 | **识别关键的少数问题**（找出造成 80% 缺陷的 20% 核心原因）。 |
| **控制图 (Control Chart)** | 包含中心线(CL)、上控制界限(UCL)和下控制界限(LCL) | **判断过程是否处于受控状态**，监控过程变异（七点规则：连续7点在中心线一侧即判定失控）。 |
| **直方图 (Histogram)** | 垂直柱状图，展示变量的频数分布 | 描述集中趋势、分散程度及统计分布形态。 |
| **散点图 (Scatter Diagram)** | 二维坐标系中的数据点云 | 研究**两个变量之间的相关性**（正相关/负相关/不相关）。 |
| **流程图 (Flowchart)** | 步骤框与流转箭头组成的业务逻辑图 | 显示系统各步骤之间的相互关系，定位缺陷产生的节点。 |
| **核查表 (Checksheet / 计数表)** | 结构化收集数据的清单与计数表格 | 现场快速收集与整理缺陷数据。 |
