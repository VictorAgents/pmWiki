# 质量管理新七大工具 (New 7 QC Tools)

## 概念定义
**质量管理新七大工具**（也称管理与规划工具）主要用于在 [[管理质量]] (质量保证) 过程中，整理想法、寻找问题根本原因、梳理逻辑关系并进行规划决策。

## 核心工具及特征
1. **亲和图 (Affinity Diagrams)**: 类似于心智图。对头脑风暴产生的大量创意进行**分组分类**，以便审查和分析。
2. **过程决策程序图 (PDPC, Process Decision Program Charts)**: 用于理解一个目标与达成目标的步骤之间的关系。有助于**预期可能发生的故障并制定应急计划**。
3. **关联图 (Interrelationship Digraphs)**: 用于展示**复杂问题中各因素之间相互交织的因果关系**（多对多关系）。
4. **树形图 (Tree Diagrams)**: 也称系统图，用于表现层次化结构。可用于分解问题或目标（如WBS、RBS、OBS都是树形图的应用）。
5. **优先矩阵 (Prioritization Matrices)**: 用于识别关键事项和备选方案，通过一系列设定权重的标准，给备选方案打分**排序**。
6. **活动网络图 (Activity Network Diagrams)**: 连线图，包括AOA(箭线图)和AON(节点图)，用于展示活动先后关系，与进度网络图类似。
7. **矩阵图 (Matrix Diagrams)**: 在行列交叉的位置展示因素、原因和目标之间的强弱关系。

## 生命周期上下文
- **应用过程**: 主要应用于 [[管理质量]]（规划和执行阶段），侧重于定性分析、计划编制和复杂问题梳理。

## 考试要点与避坑指南
- **新老区别**: 老七工具（鱼骨图、控制图、帕累托等）主要用于**质量控制**（看数据找问题）；新七工具主要用于**质量保证/规划**（理清思路、做计划）。
- **情景对应**: "大量点子要分类"选亲和图；"找复杂交织的因果关系"选关联图；"给多个方案打分选出最优"选优先矩阵。
