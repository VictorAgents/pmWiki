# 4. 项目评估报告大纲

项目评估报告大纲应包括项目概况、详细评估意见、总结和建议等内容。

（1）项目概况：包括项目基本情况；综合评估结论，即是否批准或可否贷款的结论性意见。

（2）详细评估意见。

（3）总结和建议：存在或遗留的重大问题、潜在的风险及建议等。
