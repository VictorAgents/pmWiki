# 4. 运营管理

运营管理是另外一个领域,不属于项目管理范围。

运营管理关注产品的持续生产、服务的持续提供。运营管理使用最优资源满足客户要求,以保证组织或业务持续高效地运行。运营管理重点管理把输入(如材料、零件、能源和人力)转变为输出(如产品、服务)的过程。
