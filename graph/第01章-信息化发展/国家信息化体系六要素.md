# 国家信息化体系六要素

国家信息化体系由 6 大相互关联的要素构成，构成了国家信息化建设的完整有机整体：

```
                ┌───────────────────────────────────┐
                │ 1. 信息技术应用 (龙头 / 主阵地)   │
                └─────────────────┬─────────────────┘
                                  ▼
      ┌───────────────────────────────────────────────────────┐
      │ 2. 信息资源 (核心 / 战略资源)                         │
      ├───────────────────────────────────────────────────────┤
      │ 3. 信息网络 (基础设施 / 载体)                         │
      ├───────────────────────────────────────────────────────┤
      │ 4. 信息技术和产业 (物质基础 / 技术支撑)               │
      ├───────────────────────────────────────────────────────┤
      │ 5. 信息化人才 (成功之本 / 关键因素)                   │
      └───────────────────┬───────────────────────────────────┘
                          ▼
                ┌───────────────────────────────────┐
                │ 6. 法规政策与标准规范 (保障 / 准则)│
                └───────────────────────────────────┘
```

1. **信息技术应用**：国家信息化体系的**龙头和主阵地**，是信息化建设的核心目的。
2. **信息资源**：国家信息化体系的**核心和战略资源**，开发利用信息资源是信息化的关键。
3. **信息网络**：信息传递和共享的**基础设施**（电信网、广电网、互联网及物联网络）。
4. **信息技术和产业**：信息化建设的**物质技术基础**。
5. **信息化人才**：国家信息化建设的**成功之本和决定性力量**。
6. **法规政策与标准规范**：信息化健康发展的**根本保障与规范准绳**。
