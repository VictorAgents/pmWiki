# 信息传输模型 6 大部件

## 1. 结构模型
通用信息传输系统模型包含以下 6 大关键组成部件：

```
[信源] ---> [编码器] ---> [信道 (含噪声)] ---> [译码器] ---> [信宿]
```

## 2. 核心部件功能详解
1. **信源 (Source)**：产生信息的实体或系统（如发话人、传感器、计算机应用）。
2. **编码器 (Encoder)**：将信源发出的原始信息转换成适合在信道上传输的信号（如将模拟语音转换为数字脉冲）。
3. **信道 (Channel)**：传输信号的物理或逻辑媒介（如双绞线、光纤、无线电波）。
4. **噪声 (Noise)**：信道中存在的干扰信号，会导致传输信号失真或出错。
5. **译码器 (Decoder)**：编码器的逆变换设备，把接收到的信道信号还原为信宿可识别的原始信息。
6. **信宿 (Sink)**：信息的最终接收者和使用者（如听话人、终端应用、存储设备）。

## 3. 主要性能指标
- **有效性 (传输速率)**：单位时间内传输的信息量（如带宽、波特率）。
- **可靠性 (抗干扰能力)**：传输过程中信息的正确率（如误码率 BER）。
