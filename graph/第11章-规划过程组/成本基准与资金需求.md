# 成本基准与项目资金需求

## 1. 成本基准 (Cost Baseline) 的构成
成本基准是经批准的按时间段分配的项目预算（不包括任何管理储备），只有通过正式的变更控制程序才能变更，用作与实际结果进行比较的依据。通常表现为一条 **S 曲线 (S-Curve)**。

```
[工作包成本估算] + [活动应急储备] = [控制账户预算]
                                        │
                                        ▼
                                  [成本基准 (BAC)]  <--- 项目经理可直接支配
                                        │ + [管理储备] (针对未知-未知风险，需高层审批)
                                        ▼
                                  [项目总预算]
```

## 2. 应急储备 vs 管理储备对比
| 储备类型 | 应对风险类型 | 是否包含在成本基准中 | 动用审批权限 |
| :--- | :--- | :--- | :--- |
| **应急储备 (Contingency Reserve)** | **“已知-未知”风险** (已识别但发生概率和影响不确定的风险) | **包含在成本基准 (BAC) 中** | **项目经理有权直接决定动用** |
| **管理储备 (Management Reserve)** | **“未知-未知”风险** (未识别的重大突发不可预见事件) | **不包含在成本基准中**，包含在项目总预算中 | **需走变更流程，经高层或发起人正式批准** |
