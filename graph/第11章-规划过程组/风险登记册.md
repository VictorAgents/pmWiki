# 风险登记册 (Risk Register)

## 1. 概念定义
风险登记册是记录已识别单个项目风险的详细信息的文件。随着项目生命周期的推进和风险管理过程的实施，风险登记册会不断更新，是风险管理的核心项目文件。

## 2. 核心内容
在不同阶段，其内容会有所增加：
- **识别风险后**：已识别风险的清单、潜在风险应对措施清单、潜在风险责任人。
- **定性分析后**：每项风险的概率和影响评估、风险评分或等级、风险紧迫性。
- **定量分析后**：概率影响量化数据。
- **规划应对后**：选定的应对策略（如规避、转移、减轻、接受）、具体的应对行动、应对策略所有者。

## 3. 生命周期流转 (ITTO)
- **产生过程**：[[11.19 识别风险]] 的主要输出。
- **渐进明细与更新**：在 [[11.20 实施定性风险分析]]、[[11.21 实施定量风险分析]]、[[11.22 规划风险应对]]、[[12.8 实施风险应对]] 和 [[13.8 监督风险]] 中被不断更新。
- **作为输入**：作为项目文件，它是几乎所有后续规划、执行和监控过程的重要输入（超过10个过程需要参考风险登记册以规避风险）。

## 4. 考试要点 (Exam Takeaways)
- **风险分类**：不要把风险和问题混淆。风险登记册记录未来可能发生的不确定事件；一旦风险发生，就变成了问题，需要记入[[问题日志]]。
- **动态更新**：风险登记册是一个动态文件，贯穿项目始终。
