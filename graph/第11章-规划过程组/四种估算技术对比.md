# 四种估算技术对比 (Estimation Techniques Comparison)

## 概念定义
在项目管理中，时间（进度）、成本和资源的估算主要使用四种核心技术：**类比估算**、**参数估算**、**三点估算**和**自下而上估算**。

## 核心对比分析

| 估算技术 | 核心特征与机制 | 准确度与成本 | 适用场景 |
|---------|--------------|-------------|---------|
| **类比估算 (Analogous)** | 基于历史类似项目的实际数据进行估算。是一种**自上而下**的估算。 | 准确度低，成本低，耗时短 | 项目初期，详细信息不足时；需要快速粗略估算时。 |
| **参数估算 (Parametric)** | 基于历史数据和项目参数建立统计关系（如：代码行数×每行代码成本）。 | 准确度取决于模型的可靠性和数据的准确性 | 有成熟的参数模型，数据可量化（如建筑平米造价）。 |
| **三点估算 (Three-Point)** | 考虑不确定性和风险，使用最乐观(O)、最悲观(P)和最可能(M)三个值计算期望值。 | 准确度较高 | 活动持续时间或成本存在较大不确定性时。 |
| **自下而上估算 (Bottom-up)**| 对最底层组件（工作包或活动）进行估算，然后逐层汇总。 | **准确度最高**，成本最高，耗时最长 | 项目范围明确，需要高精度预算或进度基准时。 |

### 三点估算公式 (PERT)
- **贝塔分布 (Beta Distribution, 默认)**: 
  - 期望值 $E = (O + 4M + P) / 6$
  - 标准差 $\sigma = (P - O) / 6$
- **三角分布 (Triangular Distribution)**: 
  - 期望值 $E = (O + M + P) / 3$

## 生命周期上下文
- **广泛应用**: 这四种估算技术在 [[估算活动持续时间]]、[[估算成本]]、[[估算活动资源]] 过程中都是核心工具。

## 考试要点与避坑指南
- **类比 vs 参数**: 类比是看"整体或相似项目"，如"上个系统开发花了100万，这个也差不多"；参数是看"单价/变量"，如"100元/平方米，500平米就是5万"。
- **PERT计算**: 考试必考公式，记住"4M在中间，除以6"。以及标准差越小，风险越低；标准差越大，风险越高。
