# 团队章程 (Team Charter)

## 1. 概念定义
团队章程是为项目团队创建团队价值观、共识和工作指南的文件。它明确了团队成员的期望行为，旨在减少误解、提高生产力，并作为团队建设的重要基础。

## 2. 核心内容
- **团队价值观**
- **沟通指南**（如多久开一次会，沟通渠道）
- **决策标准与过程**（如何达成一致）
- **冲突处理过程**（出现分歧时的上报和解决机制）
- **会议指南**
- **团队共识和基本规则**（Ground Rules）

## 3. 生命周期流转 (ITTO)
- **产生过程**：[[11.15 规划资源管理]] 过程的输出。通常由项目团队成员共同制定，以增强归属感和承诺。
- **应用阶段**：在整个项目执行阶段，特别是 [[12.5 管理团队]] 和建设团队过程中，作为规范行为的基准。

## 4. 考试要点 (Exam Takeaways)
- **尽早制定并共同参与**：由团队**共同制定**比项目经理单方面宣布更有效。
- **基本规则 (Ground Rules)**：遇到团队冲突或成员行为不规范的考题，首先要查阅或重申“团队章程”或“基本规则”。
