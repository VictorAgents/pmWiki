# 紧前关系绘图法PDM与箭线图法ADM

## 概念定义
**紧前关系绘图法 (PDM, Precedence Diagramming Method)** 和 **箭线图法 (ADM, Arrow Diagramming Method)** 是构建项目进度网络图的两种基础技术。

### 1. 紧前关系绘图法 (PDM / 单代号网络图 / AON)
使用**节点 (Node)** 代表活动，使用**箭线 (Arrow)** 代表活动之间的逻辑依赖关系。这是绝大多数项目管理软件（如MS Project）采用的方法。

PDM 支持四种逻辑关系：
- **完成到开始 (FS, Finish-to-Start)**: 紧前活动完成，紧后活动才能开始。(最常见)
- **完成到完成 (FF, Finish-to-Finish)**: 紧前活动完成，紧后活动才能完成。
- **开始到开始 (SS, Start-to-Start)**: 紧前活动开始，紧后活动才能开始。
- **开始到完成 (SF, Start-to-Finish)**: 紧前活动开始，紧后活动才能完成。(最罕见)

### 2. 箭线图法 (ADM / 双代号网络图 / AOA)
使用**箭线 (Arrow)** 代表活动，使用**节点 (Node)** 代表事件。
- ADM 仅支持**完成到开始 (FS)** 这一种逻辑关系。
- 经常需要使用**虚活动 (Dummy Activity)**（用虚线表示，不消耗时间和资源）来正确表达逻辑关系。

## 生命周期上下文
- **应用过程**: 作为 [[排列活动顺序]] 的核心工具与技术，其输出是项目进度网络图。

## 考试要点与避坑指南
- **对应关系**: PDM = 单代号 = AON = 节点是活动 = 4种关系；ADM = 双代号 = AOA = 箭线是活动 = 只有FS关系 = 需用虚活动。
- **默认关系**: 如果没有特别说明，活动之间的默认关系是 **完成到开始 (FS)**。
