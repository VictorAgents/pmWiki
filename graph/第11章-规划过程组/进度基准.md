# 进度基准 (Schedule Baseline)

## 1. 概念定义
进度基准是经过批准的进度模型，只有通过正式的变更控制程序才能进行变更，用作与实际结果进行比较的依据。它是项目管理计划的组成部分，是三大核心基准（范围、进度、成本）之一。

## 2. 核心内容与表现形式
- **内容**：包含了项目活动的基准开始日期和基准结束日期。
- **表现形式**：通常以横道图（甘特图）、里程碑图或项目进度网络图的形式表示。其中甘特图最为直观，常用于向管理层汇报。

## 3. 生命周期流转 (ITTO)
- **产生过程**：[[11.10 制订进度计划]] 的核心输出。
- **作为输入**：
  - [[12.1 指导与管理项目工作]]：用于执行项目工作。
  - [[13.4 控制进度]]：用于将实际进度与基准进行对比，计算进度偏差（SV）和进度绩效指数（SPI）。
  - [[11.11 规划成本管理]] / [[11.13 制定预算]]：由于进度与成本高度相关，时间安排直接影响资金支出计划。

## 4. 考试要点 (Exam Takeaways)
- **变更控制**：进度基准一旦确立，任何变更都必须经过[[13.6 实施整体变更控制]]过程。不能由项目经理单方面修改。
- **与实际进度的对比**：考试常考SV（进度偏差）和SPI（进度绩效指数）的计算，比较基准正是进度基准。
