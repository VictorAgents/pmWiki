# 项目进度网络图 (Project Schedule Network Diagram)

## 1. 概念定义
项目进度网络图是项目进度活动之间的逻辑关系（依赖关系）的图形展示。它是关键路径法（CPM）等进度网络分析工具的基础。

## 2. 核心元素与画法
- **节点（Node）**：代表活动。
- **箭线（Arrow）**：代表逻辑关系。
- **常用方法：紧前关系绘图法 (PDM)**，又称单代号网络图（AON）。包含四种逻辑关系：
  1. 完成到开始 (FS)：最常用。
  2. 完成到完成 (FF)。
  3. 开始到开始 (SS)。
  4. 开始到完成 (SF)：极少使用。

## 3. 生命周期流转 (ITTO)
- **产生过程**：主要由 [[11.8 排列活动顺序]] 产生。
- **作为输入**：是 [[11.10 制订进度计划]] 的核心输入，结合活动持续时间估算，才能计算出**关键路径**。

## 4. 考试要点 (Exam Takeaways)
- 必须掌握单代号网络图的六时标注法（ES, EF, LS, LF, DU, TF, FF），并在草稿纸上进行**正推法**和**逆推法**计算。
- 只有依赖关系（顺手序），没有时间（持续时间）的网络图被称为纯逻辑网络图。
